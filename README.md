# CloudeCodeTest

## ルーレット

ブラウザで動作する単一ファイルのルーレットです(外部ライブラリ・ビルド不要)。

### 使い方

1. `index.html` をブラウザで開く(または GitHub Pages 等の静的ホスティングに配置する)。
2. 右側(スマートフォンでは下側)のテキスト欄に、1行に1項目ずつ入力する。
3. 「スタート」を押すと盤面が回転し、停止位置の項目が結果として表示される。

### 仕様

- 当選項目は `crypto.getRandomValues` による乱数で各項目等確率に選択する。
- 停止位置は区画の内側 10%〜90% とし、境界線上で停止しないようにする。
- 入力内容はブラウザの `localStorage` に保存する(利用できない環境では既定値を使用)。
- 「当選した項目を次回から除外する」をチェックすると、当選項目を一覧から削除する。
- 「スタート」押下後、結果が確定するまで(結果表示と除外処理の完了まで)は、ボタンの再押下を無視する。

### 評価

`tests/spin-lock.test.mjs` は、回転中の連打(マウス・ダブルクリック・キーボード・スクリプト呼び出し・`disabled` を外した状態)に対し、結果の確定が1回のみであることを Playwright で検証する。

```sh
NODE_PATH=$(npm root -g) node tests/spin-lock.test.mjs
```
