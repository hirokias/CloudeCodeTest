# 【受講者用マニュアル】AIエージェントと回すソフトウェア開発V字モデル演習

本演習では、AIコーディングエージェント「Claude Code (Web版)」をパートナーに迎え、ソフトウェア開発の「V字モデル」を体験します。
受講者の皆さんの個人PCへのアプリケーションのインストールや、演習後の環境削除の手間は一切ありません。ブラウザだけで次世代のDX/AX開発を体感しましょう！

---

## 🛠️ 事前準備（受講者全員が行うこと）

演習を開始する前に、以下の2つのアカウントにログインできる状態にしてください。

1. **GitHub アカウント**（各自で作成したもの）
2. **Claude アカウント**（組織のTeamプランに招待・ログインされているもの）

---

## 🚀 演習の進め方（全5ステップ）

### ステップ 1：演習用リポジトリ（倉庫）の複製
運営が用意した初期テンプレートリポジトリ（ソースコードの保管庫）を、自分のアカウントにコピーします。

1. 運営から共有された「GitHubリポジトリのURL」にブラウザでアクセスします。
2. 画面右上にある **「Fork」** ボタンをクリックします。
3. 設定はそのままで、最下部の **「Create fork」** をクリックします。
   *(※これにより、あなた専用の演習スペースがGitHub上にコピーされます)*

---

### ステップ 2：【上流工程】日本語で「要件定義」を書く
プログラミングのコードは一切書きません。あなたが作りたいアプリのアイデアを日本語で記述します。

1. コピーした自分のGitHubリポジトリの画面で、`docs/01_requirements.md` を開きます。
2. 画面右上にある **「鉛筆マーク（Edit）」** をクリックします。
3. テンプレートの虫食い部分 `[ ]` を書き換え、自分が作りたいアプリの目的や機能を日本語で入力します。
4. 入力が終わったら、画面右上の **「Commit changes...」** ボタンを押し、そのまま保存します。

---

### ステップ 3：Claude Code（Web版）の起動と連携
いよいよAIエージェントを起動し、あなたのリポジトリと接続します。

1. 新しいブラウザのタブで **[claude.ai/code](https://claude.ai)** にアクセスします。
2. 左上にある **「Select Repository（リポジトリを選択）」** をクリックします。
3. 画面の指示に従ってGitHubアカウントへの接続と、Claude GitHub Appのインストールを許可します。
4. 連携が完了したら、先ほどステップ1でForkした「自分のリポジトリ名」を選択します。

> 💡 **ここがポイント！**
> リポジトリを選択した瞬間、裏側でAI専用の安全な使い捨て開発環境（クラウド・サンドボックス）が自動で立ち上がります。あなたがブラウザを閉じれば勝手に消去されるため、演習後に「環境の削除忘れ」を心配する必要はありません。

---

### ステップ 4：【下流工程】AIへの丸投げ指示（詳細設計・実装・単体テスト）
ここからはAIエージェント「Claude Code」があなたの部下となり、V字モデルの右側を自律的に駆け上がります。

1. `claude.ai/code` のチャット入力欄に、以下の指示（プロンプト）をそのまま貼り付けて送信してください。

   ```text
   docs/01_requirements.md の要件定義を読み込んでください。
   内容を理解したら、リポジトリのルートにある「CLAUDE.md」のルールに厳格に従い、
   詳細設計の作成、アプリケーションの実装、そして単体テストの作成と実行までを
   自律的に進めてください。テストがすべてパスするまで自動デバッグを繰り返してください。
   ```

2. **AIの自律駆動を観察する：**
   Claude Codeが自動的に要件定義を読み、必要なファイルを生成し、裏側でテストコマンド（`pytest`など）を叩いてバグを自己修正していく様子をリアルタイムで観察してください。
3. **完了報告の確認：**
   すべてのテストが成功（パス）すると、Claude Codeから「実装とテストが完了しました」と丁寧な日本語で報告があります。

---

### ステップ 5：【テスト工程】成果物の確認（疑似結合テスト）
AIが正しく要件通りのシステムを作れたか、最終確認を行います。

1. Claude Codeから成果物の報告を受け取ったら、チャットで **「ここまでの成果をプルリクエスト（PR）にまとめてGitHubにプッシュしてください」** と指示します。
2. Claude Codeが自動的にGitHub上に「プルリクエスト」を作成します。
3. 提示されたリンクからGitHubの画面に移動し、日本語の要件定義からどんなコードとテストコードが自動生成されたのかを確認してください。
4. 問題がなければ、演習の最終ステップとして「Merge pull request（マージ）」を押し、上流の要件と下流の成果物が一致したことを確認して演習完了です！

### 🌐 ステップ 6：ブラウザ上で実際にアプリを動かしてみる（最終結合テスト）

AIが作った「交通費精算シミュレーター」を、ブラウザ上で実際に触ってテストします。

1. **GitHubでプルリクエストをマージする**
   - ステップ5で作成したプルリクエスト（PR）の画面で、**「Merge pull request」** ➡️ **「Confirm merge」** の順にボタンをクリックします。
   - *(※これにより、AIが作った最新のコードがあなたのリポジトリのメイン（main）に反映されます)*

2. **Streamlit Community Cloud にアクセスする**
   - ブラウザで **[share.streamlit.io](https://share.streamlit.io)** にアクセスし、GitHubアカウントでサインインします。

3. **アプリを無料デプロイ（Web公開）する**
   - 画面右上にある **「Create app」**（または「New app」）ボタンをクリックします。
   - 以下の3つの項目を選択・入力します：
     - **Repository**: あなたの「交通費精算アプリのリポジトリ」を選択
     - **Branch**: `main` を選択
     - **Main file path**: `src/app.py` と入力
   - 最下部の **「Deploy!」** ボタンをクリックします。

4. **動作確認を行う**
   - 1〜2分待つと、ブラウザ上にあなたが作った「交通費精算シミュレーター」の画面が立ち上がります！
   - 実際に「自家用車」を選んで距離を入力し、金額が正しく計算されるか、1万円を超えたら赤字で警告が出るか、CSVがダウンロードできるかを自由に触って確認（テスト）してください。
